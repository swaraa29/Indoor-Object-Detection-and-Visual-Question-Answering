# Indoor-Object-Detection-and-Visual-Question-Answering
Indoor Visual Question Answering (VQA) system integrating YOLOv8 for object detection and BLIP-2 for vision-language reasoning with a Smart Question Routing (SQR) module to reduce hallucinations and improve spatial grounding. Achieved 83.3% task completion and 80% high-confidence responses on SUN RGB-D.
